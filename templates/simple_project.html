A separate Python IDLE program using numbered menus and MySQL. Copy the code below into a new IDLE file, set your database password, and run it from the shell.

Get the IDLE code ↓
01

Create the tables

Run the SQL in MySQL Workbench or from a MySQL command prompt. It creates a separate database named item_inventory_simple.

02

Install the connector

In a terminal, run py -m pip install mysql-connector-python. Edit DB_CONFIG near the top of the Python file.

03

Run in IDLE

Save the copied code as simple_inventory.py, open it in IDLE, and choose Run → Run Module. Use the first-run menu option to create an admin.
